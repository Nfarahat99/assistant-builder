# القائمة النهائية والانتقال لتيليجرام (الخطوة ٧)

> هذا الملف يغطي: الخطوة ٧. السابق: [Railway](08-railway.md). التالي (عند الطلب): [واتساب لاحقاً](whatsapp-later.md).

اعرض القائمة وعلّم على كل بند (✅ أو ⚠️ مع السبب):

- [ ] `assistant.config.json` مكتوب، والفحص ✅، ومرفوع لـ GitHub (ومعه `knowledge/owner.md` لو سوينا الأسئلة الشخصية هنا).
- [ ] `.env` فيه `TELEGRAM_BOT_TOKEN` و`GEMINI_API_KEY` و`TELEGRAM_LINK_CODE` و`DASHBOARD_PASSWORD` و`SECRETS_KEY` و`WEBHOOK_SECRET` (و`GITHUB_TOKEN`).
- [ ] أسرار GitHub: `CLAUDE_CODE_OAUTH_TOKEN` (و`TEMPLATE_SYNC_TOKEN` إن أمكن) — هو أو صاحب المستودع ([٤.٤](06-secrets.md)).
- [ ] Railway: المشروع + PostgreSQL + Volume (`FILES_DIR=/data/files`) + المتغيرات + الرابط العام، و`/health` يرد `"ok":true`.
- [ ] `npm run doctor -- --online` بدون ❌.

ثم **اربطه بالبوت برابط مباشر** (بعد ما يصير النشر أخضر و`/health` يرد):

1. شغّل أنت: `npm run telegram-link`. يقرأ `.env`، ويتأكد من البوت، ويفتح رابط البوت في المتصفح **بدون ما يطبع الرمز**.
2. قل له: «انفتح لك رابط بوتك — اضغط **Start** (أو «ابدأ»). لو سألك المتصفح، اختر فتح تيليجرام». يشتغل من تيليجرام الكمبيوتر أو الويب، والربط لحسابه في كل أجهزته (يكمّل من الجوال عادي).
3. **لو ما انفتح الرابط أو ما رد البوت** (البديل): قل له يفتح بوته في تيليجرام ويكتب `/start` ثم مسافة ثم قيمة `TELEGRAM_LINK_CODE` — افتح له `.env` (`notepad .env` أو `open -e .env`) **بدون ما تقرأه أو تعرض الرمز أنت**.

**وش يشوف:** البوت يرحّب فيه، و— لو اختار «لاحقاً في المحادثة» في [الخطوة ١](03-questions.md) — يبدأ **المقابلة الشخصية** (أسئلة قصيرة يجاوبها بصوت أو بنص؛ «تخطّ» يتجاوز، «وقف المقابلة» يوقفها، «كمّل المقابلة» يرجّعها). لو سوينا الأسئلة هنا، المساعد يعرفه من أول رسالة.

وذكّره:
- **لوحة التحكم:** رابط Railway + `/dashboard`، وكلمة المرور = `DASHBOARD_PASSWORD`.
- **واتساب لاحقاً:** اللوحة ← **الحسابات** — والمطلوب في [واتساب لاحقاً](whatsapp-later.md).
- لو صار أي شي: «شغّل npm run doctor واشرح لي النتيجة» (جدول الحلول في `docs/START-HERE.md` القسم ٧ في مستودع المساعد).
