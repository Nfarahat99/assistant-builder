# إعداد سابق؟ استئناف (الخطوة ٠.٥)

> هذا الملف يغطي: الخطوة ٠.٥. السابق: [الريبو](01-repo.md). التالي: [الأسئلة](03-questions.md).

الجلسة طويلة وممكن تنقطع. قبل الترحيب:

1. لو `assistant.config.json` موجود **و** `.env` موجود (تحقق بـ `test -f .env` بدون ما تقرأه)، شغّل `npm run doctor`.
2. لو سطر ملف الإعدادات ✅ (يعني مو على القيم التجريبية): اسأله بـ AskUserQuestion: «لقيت إعداد سابق لمساعدك. نكمّل من وين وقفنا؟» (`نكمّل من أول شي ناقص` / `نبدأ من جديد`).
3. لو «نكمّل»: شغّل `npm run doctor -- --online` وانتقل لأول بند ناقص بهذا الترتيب:

| أول بند ناقص | ارجع إلى |
|---|---|
| ❌ ملف الإعدادات | [الخطوة ٢](03-questions.md) |
| ⚠️ TELEGRAM_LINK_CODE / ❌ ما فيه قناة / ❌ توكن تيليجرام غلط | [٤.١](06-secrets.md) ثم [٤.٢](06-secrets.md) |
| ⚠️ ما فيه GEMINI_API_KEY / ❌ مفتاح Gemini غلط | [٤.٣](06-secrets.md) |
| كل الفحص بدون ❌ | اسأله (AskUserQuestion، سؤال لكل بند) عن اللي ما يشوفه الفحص: أسرار GitHub ([٤.٥–٤.٦](06-secrets.md))، رفع الإعدادات ([الخطوة ٥](07-push.md))، Railway و`/health` ([الخطوة ٦](08-railway.md))، ربط تيليجرام ([الخطوة ٧](09-finish.md)) — وكمّل من أول «لا» |

   الإجابات اللي تحتاجها لاحقاً (الاسم، نوع المستخدم، اللغة، الفرع…) خذها من `assistant.config.json` بدل ما تعيد السؤال.
4. لو «نبدأ من جديد»: كمّل من [الخطوة ١](03-questions.md) عادي. مولّد الأسرار ([٤.١](06-secrets.md)) ما يغيّر أي قيمة موجودة في `.env`.
