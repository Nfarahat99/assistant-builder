# اكتب assistant.config.json وافحصه (الخطوة ٣)

> هذا الملف يغطي: الخطوة ٣. السابق: [الأسئلة](03-questions.md). التالي: [الأسئلة الشخصية](05-personal.md) (لو اختار «هنا الحين») وإلا [الأسرار](06-secrets.md).

1. ابنِ الملف من الإجابات (لا أسرار فيه أبداً). **بدّل كل `<…>` بإجابته المؤكَّدة — لا تنسخ أي قيمة بين `<>` حرفياً.** احتفظ بقيمة `github.template_repo` الموجودة حالياً في الملف كما هي (لا تغيّرها):

## قالب الإعدادات

```json
{
  "owner": { "name": "<اسمك>" },
  "assistant": { "name": "<اسم المساعد>" },
  "language": "<ar|en>",
  "timezone": "Asia/Riyadh",
  "workweek": [<أيام الدوام المؤكَّدة، مثل 0,1,2,3,4>],
  "signature": "",
  "user_type": "<programmer|non_programmer>",
  "github": { "owner": "<owner>", "self_repo": "<owner>/<name>", "default_branch": "<الفرع المؤكَّد>", "template_repo": "<كما هو في الملف الحالي>" },
  "self_aliases": [],
  "interests": "<الاهتمامات أو فارغ>",
  "hosting": { "provider": "railway" },
  "direct_send_allowlist": []
}
```

   (تفاصيل كل حقل في `docs/TEMPLATE.md` القسم ٢. `timezone` ثابت على `Asia/Riyadh` حالياً.)
2. شغّل `npm run doctor`. **المطلوب الحين: سطر ملف الإعدادات ✅** («ملف الإعدادات سليم — المساعد …»). باقي السطور (❌ ما فيه قناة، ⚠️ المفاتيح…) طبيعية لأن الأسرار ما انحطت بعد — طمّن المالك.
3. لو سطر الإعدادات ❌: اقرأ الرسالة، صحّح الحقل المذكور، وأعد الفحص.
